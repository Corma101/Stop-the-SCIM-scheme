# Stop the SCIM Scheme

Community directory of SaaS apps: SCIM support, pricing tiers, and related context—so teams can see which vendors treat automated provisioning as a baseline feature versus a paid add-on.

## Run locally

Requires [Node.js](https://nodejs.org/) and npm.

```sh
git clone https://github.com/Corma101/Stop-the-SCIM-scheme.git
cd Stop-the-SCIM-scheme
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```sh
npm run build
npm run preview   # optional: serve production build locally
```

## Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
